# Changelog

## 2.1.1

- First launch asks for a default browser and starts with an empty rule list.
- Existing saved routing preferences survive the update.
- Separate Apple silicon and Intel release assets can be built without running Intel code on Apple silicon.
- Added a settings screenshot, routing examples, and a PayPal donation link.

## 2.1.0

- First planned GitHub release under the name Browser Switchboard.
- English and German interface with automatic system language detection and a manual override.
- Universal macOS build for Apple silicon and Intel.
- Default browser, per-app browser rules, and a per-link chooser.
- Green globe app icon and local settings storage.
